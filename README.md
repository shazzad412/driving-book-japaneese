## Japan Driving Quiz (Japanese + Bangla)

This is a single-file, mobile-friendly practice quiz for Bangladeshi learners
preparing for Japan's provisional (仮免許 / Karimen) and full (本免許 / Honmen)
driving-license tests.

### Run locally
Open `index.html` in a modern browser. Quiz progress and dark-mode preference
are stored in that browser's localStorage.

### Publish with GitHub Pages
1. Keep `index.html` in the repository root.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then save.
5. Open the published Pages URL shown on that settings page.

### Add this website to a phone
Open the GitHub Pages URL in the phone browser and use **Add to Home Screen**.
For a fuller installable application later, add a web app manifest and service
worker (PWA), test offline behavior, and provide an app icon. A native Android
or iOS app can later be built with a framework such as React Native or Flutter;
keep the quiz content in a reviewed data file and verify traffic-rule updates
before each release.

### Question source note
The included items are original practice questions, not a verified archive of
official questions from 2010–2026. Check current Japanese police, licensing
center, and driving-school materials for authoritative rules and exam content.
